# Anoma

> Anoma is a distributed operating system that abstracts blockchain complexity into a single intent-centric interface, letting developers build applications once and run them across any chain. It offers generalized intents for improved UX, programmable and compliance-ready privacy, and the Anoma Resource Machine (ARM) for native intents, interoperability, and scaling.
